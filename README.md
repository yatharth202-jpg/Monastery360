# 🛕 Monastery360 — Heritage Guardian (SIH25061)

> **Government of Sikkim Monastic Heritage Protection & Decay Reporting Module**  
> Built for **Smart India Hackathon (SIH25061)** in partnership with the **Department of Tourism & Civil Aviation, Government of Sikkim** and **Archaeological Survey of India (ASI Sikkim Circle)**.

---

## 🌟 Key Features

- **🏛️ Sacred Monasteries Directory**: High-resolution showcase of 6 historic Sikkimese sanctuaries (*Rumtek, Pemayangtse, Tashiding, Labrang, Dubdi, Tholung*).
- **📸 5-Step Guided Decay Reporting**: Stepper workflow with simulated AI Computer Vision pre-scan & automatic government department routing.
- **🤝 Community Alerts & Adopt-a-Repair**: Upvoting system for community reports & sponsorship handoff module with 80G tax exemption details.
- **📁 Clean Separation of Concerns**: Pure modular architecture (`index.html`, `css/styles.css`, `js/app.js`).
- **🌐 8-Language Switcher**: English, Hindi, Nepali, Sikkimese (Bhutia), Dzongkha, Japanese, Mandarin, French.
- **☀️/🌙 Adaptive Theme Switcher**: Dynamic Light Mode & 3D Glassmorphism Dark Mode.

## 🚀 Quick Start

Simply double-click `index.html` or open it with any web browser or VS Code Live Server.

